# Heavenly Beauty Spa Website

A stunning, interactive website for Heavenly Beauty Spa, featuring modern design and cutting-edge animations.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices.
- **Interactive Elements**:
  - Floating particle background using Particles.js
  - Animated text with bouncing letters
  - 3D flip cards for services
  - Interactive booking modal
  - Parallax scrolling effects
  - Liquid blob animations
  - Morphing hero background
  - Holographic hover effects
  - Scroll-triggered fade-in animations
  - Enhanced button hover effects with transforms and shadows
  - Pulsing "Book Appointment" button
- **Sections**:
  - Hero with call-to-action
  - Services showcase
  - About Us
  - Contact information with booking form
  - Footer with animated background

## Technologies Used

- HTML5
- CSS3 (with animations and transitions)
- JavaScript (ES6+)
- Particles.js library

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/EAJ1/Heavenly-Beauty-Spa.git
   ```

2. Navigate to the project directory:
   ```
   cd Heavenly-Beauty-Spa
   ```

3. Open `index.html` in your web browser.

No additional setup or dependencies are required as the site uses vanilla HTML, CSS, and JS with a CDN-hosted Particles.js library.
